# Roomset messaging

## One sentence
Roomset helps you explore how a sofa could fit into your space through an editable 3D room plan.

## Short introduction
Start with a sofa listing and a few photos of your corner. Confirm the dimensions, help set the room scale, then move and rotate a dimensioned model to compare arrangements before you buy.

## Honest interface language
| Situation | Copy |
|---|---|
| Dimensions missing | Add the width, depth and height from the listing. |
| Poor photo | Take another photo with the same corner in view. |
| Calibration | Enter the distance between these two points. |
| Assisted model | Room built using your confirmed measurements. |
| Approximate asset | Dimensioned model. Shape and materials may differ from the product. |
| Unknown area | Not captured. Check this area before deciding. |
| Overlap | The sofa overlaps a modeled wall or obstacle. Try moving it. |
| Save | Layout saved. You can return to this arrangement. |
| Processing failure | We could not finish this model. Your inputs are saved; try again. |

## Presentation copy
Roomset turns a sofa listing and a small set of room photos into a spatial planning workflow. Muse interprets the inputs, a reconstruction or assisted-modeling path establishes the room, Blender creates dimensioned assets, and a browser editor lets the user explore placements.

Until end-to-end verification passes, use “we are building” and “the planned workflow” in external project claims. Do not present this copy as evidence of a finished integration.
