# Roomset brand package

Start with **preview.html** for the visual guide. Read **brand-guide.md** for rules and **messaging.md** for reusable copy. The sibling **../proposal/** folder contains the updated project proposal in Markdown, HTML and PDF.

- assets/logo/ — user-supplied logo, unchanged; opaque PNG, not a vector master.
- assets/icons/ — 12 editable UI SVGs.
- assets/illustrations/ — room-corner concept and floor grid, editable SVG.
- assets/archive/ — prior prototype artwork/tokens, reference only; not current branding.
- fonts/ — local DM Sans and Cormorant Garamond files and licenses.
- theme/ — CSS tokens/components, local font declarations, JSON tokens and contrast report.
- templates/ — editable social card, square announcement and pitch-cover compositions.
- exports/ — PNG exports and printable brand guide PDF.
- asset-manifest.json — inventory, hashes and provenance notes.

Your supplied logo is authoritative. Supporting brand choices are proposed; previous prototype files have not been changed. No transparent/vector logo or app icon is claimed. Use the original on a light panel. Do not use archived mark.png as the current identity.

The preview and templates are local brand documents. Open preview.html directly in a browser; no installation or network connection is required. UI controls are visual specimens. Keep the folder structure intact so local images and fonts resolve.

The proposal follows GitHub issues #2–#4, checked 2 November 2026. It supersedes the older image-swap concept for this deliverable, but leaves the old root PROPOSAL.md and Agent.MD unchanged. This package does not modify the application or publish anything.
